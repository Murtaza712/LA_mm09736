This video introduces the concepts of **linear dependence** and **linear independence** through vector spans. Here are the key definitions and examples provided:

### Core Definitions

*   **Span:** The set of all possible vectors that can be represented by linear combinations of a given set of vectors ($c_1v_1 + c_2v_2 + ... + c_nv_n$ for any scalars $c_i$).
*   **Linearly Dependent:** A set of vectors where at least one vector can be represented as a linear combination of the others. Adding a dependent vector does not expand the span (it adds no "new dimension").
*   **Linearly Independent:** A set of vectors where no vector can be represented as a linear combination of the others. Each vector adds new directionality, increasing the dimensionality of the span.

### Illustrative Examples

**Example 1: Collinear Vectors in $mathbb{R}^2$ (0:00 - 4:27)**

*   Vectors: $\begin{bmatrix} 2 \ 3 end{bmatrix}$ and $\begin{bmatrix} 4 \ 6 end{bmatrix}$.
*   Concept: Since $\begin{bmatrix} 4 \ 6 end{bmatrix} = 2 cdot \begin{bmatrix} 2 \ 3 end{bmatrix}$, these vectors are **linearly dependent**. They are collinear and span only a line, not the full 2D space.

**Example 2: Redundant Vectors in $mathbb{R}^2$ (7:27 - 10:23)**

*   Vectors: $\begin{bmatrix} 2 \ 3 end{bmatrix}$, $\begin{bmatrix} 7 \ 2 end{bmatrix}$, and $\begin{bmatrix} 9 \ 5 end{bmatrix}$.
*   Concept: Here, $\begin{bmatrix} 2 \ 3 end{bmatrix} + \begin{bmatrix} 7 \ 2 end{bmatrix} = \begin{bmatrix} 9 \ 5 end{bmatrix}$. Because the third vector is a sum of the first two, the set is **linearly dependent**.

**Example 3: Basis Vectors in $mathbb{R}^2$ (10:23 - 12:09)**

*   Vectors: $\begin{bmatrix} 7 \ 0 end{bmatrix}$ and $\begin{bmatrix} 0 \ -1 end{bmatrix}$.
*   Concept: Neither can be scaled to reach the other. They are **linearly independent** and span the entire $mathbb{R}^2$ plane.

**Example 4: Standard-like Vectors in $mathbb{R}^3$ (13:36 - 15:30)**

*   Vectors: $\begin{bmatrix} 2 \ 0 \ 0 end{bmatrix}$, $\begin{bmatrix} 0 \ 1 \ 0 end{bmatrix}$, and $\begin{bmatrix} 0 \ 0 \ 7 end{bmatrix}$.
*   Concept: These vectors are **linearly independent** because each has a unique, non-zero component that cannot be formed by combining the other two vectors. They span the entire 3D space ($mathbb{R}^3$).

This video explores the relationship between **span** and **linear independence** for a set of three-dimensional vectors. Here are the key definitions, examples, and logical formulas presented:

### Definitions

*   **Span of a set of vectors ($S$):** The set of all possible linear combinations of the vectors in $S$. If the span of $S$ equals $mathbb{R}^3$, it means any vector in $mathbb{R}^3$ can be constructed by scaling and adding these vectors (0:57).
*   **Linearly Independent:** A set of vectors is linearly independent if the only solution to the equation $c_1\vec{v_1} + c_2\vec{v_2} + c_3\vec{v_3} = \vec{0}$ is $c_1 = c_2 = c_3 = 0$ (12:17, 13:20).

### Example Vectors

The narrator uses a set $S$ of three vectors in $mathbb{R}^3$:

*   $\vec{v_1} = \begin{bmatrix} 1 \ -1 \ 2 end{bmatrix}$, $\vec{v_2} = \begin{bmatrix} 2 \ 1 \ 3 end{bmatrix}$, $\vec{v_3} = \begin{bmatrix} -1 \ 0 \ 2 end{bmatrix}$ (1:11-1:33).

### Formulas and Procedures

To determine if the set spans $mathbb{R}^3$, the narrator sets up a linear combination equal to an arbitrary vector $\begin{bmatrix} a \ b \ c end{bmatrix}$:
$$c_1 \begin{bmatrix} 1 \ -1 \ 2 end{bmatrix} + c_2 \begin{bmatrix} 2 \ 1 \ 3 end{bmatrix} + c_3 \begin{bmatrix} -1 \ 0 \ 2 end{bmatrix} = \begin{bmatrix} a \ b \ c end{bmatrix}$$

This leads to the system of equations (2:57-3:41):

1.  $c_1 + 2c_2 - c_3 = a$
2.  $-c_1 + c_2 = b$
3.  $2c_1 + 3c_2 + 2c_3 = c$

Through Gaussian elimination, the narrator solves for the constants:

*   $c_3 = \frac{1}{11}(3c - 5a + b)$ (9:01, 10:46)
*   $c_2 = \frac{1}{3}(b + a + c_3)$ (9:38)
*   $c_1 = a - 2c_2 + c_3$ (10:01)

Because these constants can be solved for any arbitrary $a, b, c$, the set spans $mathbb{R}^3$. By setting $a=b=c=0$, the narrator proves that $c_1=c_2=c_3=0$, confirming the vectors are **linearly independent** (14:15-15:05).

This video introduces the concept of a **linear subspace** of $mathbb{R}^n$ and provides the formal definition, examples, and proof of properties.

### **Definition of a Linear Subspace**

A subset of vectors $V$ in $mathbb{R}^n$ is a **linear subspace** if and only if it satisfies these three conditions (2:23):

1.  **Zero Vector:** The zero vector (a vector of $n$ zeros) is contained in $V$ (2:27).
2.  **Closure under Scalar Multiplication:** For any vector $mathbf{x} in V$ and any scalar $c in mathbb{R}$, the product $cmathbf{x}$ is also in $V$ (3:06).
3.  **Closure under Addition:** For any vectors $mathbf{a}, mathbf{b} in V$, their sum $mathbf{a} + mathbf{b}$ is also in $V$ (4:48).

### **Examples and Analysis**

*   **The Zero Vector Set:** A set containing only the zero vector in $mathbb{R}^3$ is a valid subspace (6:41). It satisfies all three conditions: it contains the zero vector, is closed under multiplication (as $c cdot mathbf{0} = mathbf{0}$), and is closed under addition ($mathbf{0} + mathbf{0} = mathbf{0}$) (7:08 - 8:20).
*   **The Half-Plane Example:** A set $S$ in $mathbb{R}^2$ where the first component $X_1 ge 0$ is **not a subspace** (9:01). While it contains the zero vector and is closed under addition, it fails closure under scalar multiplication because multiplying by a negative scalar (like $-1$) results in a vector where $X_1 < 0$, falling outside the set (13:33 - 14:10).
*   **Span of Vectors:** The span of any set of vectors (e.g., ${V_1, V_2, V_3}$) is always a valid subspace (14:46). The video proves this by showing that any linear combination $mathbf{x} = c_1 V_1 + c_2 V_2 + c_3 V_3$ is closed under scalar multiplication (16:44) and addition (18:22).
*   **Span of a Single Vector:** The span of the vector $(1, 1)$ in $mathbb{R}^2$ forms a line through the origin, which is a valid subspace (19:54). It satisfies all three conditions because any point on the line scaled or added to another point on the line remains on the line (21:06 - 23:05).

This video explores the fundamental concept of a **basis** for a subspace. Below are the definitions, proofs, and examples presented.

### **Definitions**

*   **Subspace (V):** A set equal to the span of a finite set of vectors.
*   **Span:** The set of all possible linear combinations of a collection of vectors: $c_1v_1 + c_2v_2 + dots + c_nv_n$, where $c_i$ are real numbers (0:54).
*   **Linear Independence:** A set of vectors is linearly independent if the only solution to $c_1v_1 + c_2v_2 + dots + c_nv_n = \vec{0}$ is $c_1 = c_2 = dots = c_n = 0$ (1:32).
*   **Basis:** A set of vectors $S = {v_1, v_2, dots, v_n}$ is a basis for a subspace $V$ if:
    1.  The span of $S$ equals $V$ (2:10).
    2.  The vectors in $S$ are linearly independent (2:22).
*   **Standard Basis:** The simplest basis for $mathbb{R}^2$, composed of the unit vectors $i = \binom{1}{0}$ and $j = \binom{0}{1}$ (12:52).

### **Examples**

*   **Example 1 (in $mathbb{R}^2$):** The set $S = {\binom{2}{3}, \binom{7}{0}}$ is a basis for $mathbb{R}^2$. It is proven to span $mathbb{R}^2$ (by showing any $\binom{x_1}{x_2}$ can be represented by constants $c_1, c_2$) and is linearly independent (6:14).
*   **Example 2 (Redundancy):** Adding an extra vector that can be represented as a combination of others (e.g., $v_{special} = v_1 + v_2$) makes the set **linearly dependent** and therefore disqualifies it from being a basis (3:40).

### **Proof of Uniqueness**

*   **Claim:** Every vector $A$ in a subspace $U$ can be represented by a **unique** linear combination of the basis vectors.
*   **Proof by Contradiction:**
    1.  Assume $A$ has two representations: $A = sum c_i v_i$ and $A = sum d_i v_i$ (14:33).
    2.  Subtracting the two gives $\vec{0} = sum (c_i - d_i) v_i$ (15:28).
    3.  Since the vectors are linearly independent, all coefficients must be zero: $c_i - d_i = 0$, implying $c_i = d_i$ (17:19).
    4.  This contradicts the assumption that the representations were different, proving the combination is unique.

This video introduces the **null space** of a matrix and proves that it forms a valid subspace. Below is a breakdown of the definitions, proofs, and conceptual examples covered:

### Definitions

*   **Subspace ($S$):** A set that satisfies three conditions:
    1.  Contains the **zero vector** ($0 in S$).
    2.  Closed under **vector addition**: If $v_1, v_2 in S$, then $v_1 + v_2 in S$ (0:33-0:49).
    3.  Closed under **scalar multiplication**: If $v_1 in S$ and $c$ is a real scalar, then $cv_1 in S$ (0:50-1:15).

## Core Concepts & Formulas

*   **Homogeneous System:** The equation $Amathbf{x} = mathbf{0}$ represents a homogeneous system of linear equations. Solving for the null space involves finding all possible vectors $mathbf{x}$ that satisfy this system.
*   **Linear Combination:** The null space is formed by the span of specific basis vectors. Any vector in the null space can be expressed as a linear combination of these basis vectors.
*   **Reduced Row Echelon Form (RREF):** The primary method to solve for the null space is to transform matrix $A$ into its RREF to clearly identify pivot and free variables.

## Definitions

*   **Column Space of a Matrix:** The set of all possible linear combinations of the column vectors of a matrix. For an $m \times n$ matrix $A$, this is the span of its columns, denoted as $\text{Col}(A)$.
*   **Span:** The set of all possible linear combinations of a given set of vectors.
*   **Subspace:** A subset of a vector space that is closed under addition and scalar multiplication, and contains the zero vector. The column space of any matrix is a valid subspace.

## Core Concepts & Interpretations

*   **Matrix as Column Vectors:** An $m \times n$ matrix $A$ can be viewed as a collection of $n$ column vectors, each having $m$ components: $A = [v_1, v_2, dots, v_n]$, where each $v_i in mathbb{R}^m$ (0:18-0:55).
*   **Matrix-Vector Product:** The product $Ax$ (where $x in mathbb{R}^n$) is equivalent to a linear combination of the column vectors of $A$:
    $$Ax = x_1v_1 + x_2v_2 + dots + x_nv_n$$
    This provides an alternative interpretation of the column space as the set of all possible values that $Ax$ can take for any $x in mathbb{R}^n$ (4:45-7:45).

## Applications to Linear Systems

*   **Solvability of $Ax = b$:**
    *   If $b$ is **in** the column space of $A$, then there exists at least one vector $x$ such that $Ax = b$ (a solution exists) (9:08-9:47).
    *   If $b$ is **not** in the column space of $A$, then the equation $Ax = b$ has no solution (8:31-9:05).

## Subspace Verification

To prove the column space is a subspace, it must be shown that:

*   **Zero Vector:** Including the zero vector (by multiplying all vectors by 0) (1:36).
*   **Closure under Scalar Multiplication:** If $a$ is in the column space and $s$ is a scalar, $s 	imes a$ is also in the column space (2:10-2:49).
*   **Closure under Addition:** If $a$ and $b$ are in the column space, $a + b$ is also in the column space (2:51-4:08).

## Definitions (0:00-25:13)

*   **Column Space:** The span of the column vectors of a matrix. It represents all possible linear combinations of the matrix's columns.
*   **Null Space:** The set of all vectors $mathbf{x}$ that satisfy the equation $Amathbf{x} = mathbf{0}$.
*   **Linear Independence:** A set of vectors is linearly independent if the only solution to the equation $c_1mathbf{v}_1 + c_2mathbf{v}_2 + ... + c_nmathbf{v}_n = mathbf{0}$ is the trivial solution where all scalars $c_i = 0$. If the null space of $A$ contains more than just the zero vector, the columns are linearly dependent.
*   **Basis:** A set of vectors that spans a subspace and is linearly independent. It contains no redundant information (no vector can be represented as a linear combination of the others).
*   **Pivot Variables:** Variables corresponding to columns in a matrix that contain a pivot entry after reduction to row echelon form.
*   **Free Variables:** Variables corresponding to columns that do not have a pivot entry; these can be assigned any value.
*   **Reduced Row Echelon Form (RREF):** A specific form of a matrix where pivot entries are 1, they are the only non-zero entries in their columns, and pivot entries are located to the right of pivots in rows above them.

*   **Logic:** Use the relationship between free variables and the original columns to identify redundant vectors.

## Definitions and Formulas

*   **Null Space of B:** The set of all vectors $mathbf{x}$ in $mathbb{R}^5$ such that $Bmathbf{x} = mathbf{0}$. The null space of a matrix is equal to the null space of its reduced row echelon form (0:00-0:50).
*   **Dimension of a Subspace:** The number of elements (vectors) in a basis for that subspace (11:00-11:40).
*   **Nullity of a Matrix:** The dimension of the null space, which is equal to the number of non-pivot columns (or free variables) in its reduced row echelon form (12:00-13:50).

## Example: Finding the Nullity of Matrix B (0:00-13:50)

### 1. Matrix B and Reduction

The initial matrix $B$ is given by:
$$\begin{bmatrix} 1 & 1 & 2 & 3 & 2 \ 1 & 1 & 3 & 1 & 4 end{bmatrix}$$

Through Gaussian elimination, the matrix is transformed into its **reduced row echelon form**:

1.  Replace Row 2 with (Row 2 - Row 1) to get:
    $$\begin{bmatrix} 1 & 1 & 2 & 3 & 2 \ 0 & 0 & 1 & -2 & 2 end{bmatrix}$$
2.  Replace Row 1 with (Row 1 - 2 * Row 2) to finalize the reduced form:
    $$\begin{bmatrix} 1 & 1 & 0 & 7 & -2 \ 0 & 0 & 1 & -2 & 2 end{bmatrix}$$

### 2. Setting up the Equations

From the reduced form, we extract the equations for the pivot variables $x_1$ and $x_3$:

*   $x_1 + x_2 + 7x_4 - 2x_5 = 0 implies x_1 = -x_2 - 7x_4 + 2x_5$
*   $x_3 - 2x_4 + 2x_5 = 0 implies x_3 = 2x_4 - 2x_5$

### 3. Basis Vectors

By expressing the vector $mathbf{x}$ as a linear combination of the free variables $x_2, x_4,$ and $x_5$, we identify the basis vectors:
$$mathbf{x} = x_2 \begin{bmatrix} -1 \ 1 \ 0 \ 0 \ 0 end{bmatrix} + x_4 \begin{bmatrix} -7 \ 0 \ 2 \ 1 \ 0 end{bmatrix} + x_5 \begin{bmatrix} 2 \ 0 \ -2 \ 0 \ 1 end{bmatrix}$$

The three resulting vectors form a **basis** for the null space. Because there are 3 vectors in this basis, the **nullity** of matrix $B$ is **3**.

## Definitions and Core Concepts (0:00 - 12:48)

*   **Column Space:** The set of all possible linear combinations of the column vectors of a matrix. It is equivalent to the **span** of these column vectors.
*   **Basis for Column Space:** A subset of the matrix's column vectors that are linearly independent and span the column space.
*   **Pivot Column:** A column in the *reduced row echelon form* (RREF) of a matrix that contains a leading entry (pivot).
*   **Rank:** The dimension of the column space of a matrix. It is equal to the number of pivot columns in the matrix.

## Methodology for Finding a Basis (0:43 - 12:20)

To identify a basis for the column space of a matrix $A$:

1.  **Reduce to RREF:** Perform row operations on matrix $A$ to transform it into its *reduced row echelon form* ($R$).
2.  **Identify Pivots:** Locate the columns in $R$ that contain pivot entries.
3.  **Map to Original:** Select the original column vectors from matrix $A$ that correspond to the positions of the pivot columns identified in step 2.

*   **Basis Construction:** Therefore, the set { $A_1, A_2, A_4$ } from the original matrix $A$ forms a basis for the column space.
*   **Determining Rank:** Since there are exactly three pivot columns, the **rank** of the matrix is $3$.
