## Definition of a Linear Transformation (0:00-1:49)

A **linear transformation** is a function $T$ that maps vectors from a domain $mathbb{R}^n$ to a codomain $mathbb{R}^m$. For $T$ to be considered a linear transformation, it must satisfy two specific conditions for any vectors $mathbf{a}, mathbf{b}$ in $mathbb{R}^n$ and any scalar $c$:

*   **Additivity:** The transformation of the sum of two vectors is equal to the sum of the transformations of the vectors:
    $T(mathbf{a} + mathbf{b}) = T(mathbf{a}) + T(mathbf{b})$

*   **Homogeneity (Scalar Multiplication):** The transformation of a scaled vector is equal to the scalar times the transformation of the vector:
    $T(cmathbf{a}) = cT(mathbf{a})$

## Example 1: A Linear Transformation (1:56-9:50)

This example defines a mapping $T: mathbb{R}^2 \to mathbb{R}^2$ as follows:
$T\begin{pmatrix} x_1 \ x_2 end{pmatrix} = \begin{pmatrix} x_1 + x_2 \ 3x_1 end{pmatrix}$

*   **Verification of Additivity:** By testing $T(mathbf{a} + mathbf{b})$ against $T(mathbf{a}) + T(mathbf{b})$, the video confirms that the first condition holds.
*   **Verification of Homogeneity:** By testing $T(cmathbf{a})$ against $cT(mathbf{a})$, the video confirms that the second condition holds.
*   **Conclusion:** Because both conditions are met, this is confirmed as a linear transformation.

## Example 2: A Non-Linear Transformation (10:01-13:45)

This example defines a mapping $T: mathbb{R}^2 \to mathbb{R}^2$ as follows:
$T\begin{pmatrix} x_1 \ x_2 end{pmatrix} = \begin{pmatrix} x_1^2 \ 0 end{pmatrix}$

*   **Testing Homogeneity:** When applying the scalar $c$, the transformation results in $T(cmathbf{a}) = c^2 T(mathbf{a})$.
*   **Conclusion:** Since $c^2 T(mathbf{a}) \neq c T(mathbf{a})$, the transformation fails the requirement for homogeneity, meaning it is **not** a linear transformation.

## Summary of Intuition (13:15-13:52)

*   **Linear Combinations:** Transformations involving only linear combinations of input components typically result in linear transformations.
*   **Non-Linear Features:** Transformations involving components multiplied by each other, powers (like $x^2$), or other exponents generally result in non-linear transformations.

## Definitions and Core Concepts (0:00-3:20)

*   **Matrix-Vector Product as a Transformation**: The video establishes that multiplying an $m \times n$ matrix $A$ by a vector $x$ from $mathbb{R}^n$ acts as a transformation $T: mathbb{R}^n \to mathbb{R}^m$, defined as $T(x) = Ax$.
*   **Column Vector Representation**: If $A$ has columns $v_1, v_2, dots, v_n$, then the product $Ax$ is defined as the linear combination:
    $$Ax = x_1v_1 + x_2v_2 + dots + x_nv_n$$
*   **Linear Transformation Requirements**: A transformation $T$ is linear if it satisfies two conditions for all vectors $a, b$ and scalars $c$:
    1.  **Additivity**: $T(a + b) = T(a) + T(b)$
    2.  **Homogeneity (Scaling)**: $T(ca) = cT(a)$

## Examples (3:58-6:04)

*   **Specific Transformation Example**: The video uses matrix $B = \begin{bmatrix} 2 & -1 \ 3 & 4 end{bmatrix}$ to define a transformation $T: mathbb{R}^2 \to mathbb{R}^2$.
*   **Calculation**:
    $$T(x) = \begin{bmatrix} 2 & -1 \ 3 & 4 end{bmatrix} \begin{bmatrix} x_1 \ x_2 end{bmatrix} = \begin{bmatrix} 2x_1 - x_2 \ 3x_1 + 4x_2 end{bmatrix}$$
*   **Alternative Notation**: This is expressed as $T(x_1, x_2) = (2x_1 - x_2, 3x_1 + 4x_2)$.

## Proofs and Formal Laws (6:49-14:45)

*   **Proof of Additivity**: Shows that $A(a + b) = Aa + Ab$ by expanding the linear combination:
    *   Substitutes $x_i$ with $(a_i + b_i)$.
    *   Distributes vectors across the sum.
    *   Regroups terms corresponding to vector $a$ and vector $b$ to reach $Aa + Ab$.
*   **Proof of Homogeneity**: Shows that $A(ca) = c(Aa)$:
    *   Computes $A(ca)$ where the vector entries are $ca_i$.
    *   Factors the scalar $c$ out of the sum of column vectors.
    *   Identifies the resulting expression as $c(Aa)$.

## Conclusion and Real-World Application (14:46-17:04)

*   **Fundamental Takeaway**: All matrix-vector products are linear transformations.
*   **Future Scope**: The video previews the next lesson, which will cover the converse: every linear transformation can be represented as a matrix-vector product.
*   **Application**: Mentions that 3D graphics engines (in gaming hardware like *Xbox* or *PlayStation*) are essentially "hardwired" matrix multipliers that perform these linear transformations to rotate and render objects in 3D space.

## I. The Identity Matrix ($I_n$) (0:00-3:37)

*   **Definition:** An $n \times n$ matrix with ones on the main diagonal and zeros everywhere else.
*   **Identity Property:** Multiplying the identity matrix by any vector $x$ in $mathbb{R}^n$ results in the original vector: $I_n x = x$.
*   **Examples:**
    *   $I_2 = \begin{bmatrix} 1 & 0 \ 0 & 1 end{bmatrix}$
    *   $I_3 = \begin{bmatrix} 1 & 0 & 0 \ 0 & 1 & 0 \ 0 & 0 & 1 end{bmatrix}$

## II. The Standard Basis for $mathbb{R}^n$ (3:38-6:11)

*   **Definition:** The set of columns of the identity matrix, denoted as ${e_1, e_2, dots, e_n}$.
*   **Properties:**
    *   They span $mathbb{R}^n$ (any vector can be written as a linear combination of these).
    *   They are linearly independent.
    *   They are orthonormal: each has a length of 1, and the dot product of any two distinct basis vectors is 0.
*   **Vector Representation:** Any vector $x$ can be expressed as a linear combination of the standard basis: $x = x_1 e_1 + x_2 e_2 + dots + x_n e_n$.

## III. Linear Transformations as Matrix-Vector Products (6:12-10:53)

*   **Key Theorem:** Every linear transformation $T: mathbb{R}^n \to mathbb{R}^m$ can be represented as a matrix-vector product $Ax$, where $A$ is an $m \times n$ matrix.
*   **Construction of Matrix A:** The columns of the matrix $A$ are the transformation of each standard basis vector: $A = \begin{bmatrix} T(e_1) & T(e_2) & dots & T(e_n) end{bmatrix}$.
*   **Linearity Rules used:**
    1.  $T(x_1 e_1 + x_2 e_2 + dots + x_n e_n) = T(x_1 e_1) + T(x_2 e_2) + dots + T(x_n e_n)$
    2.  $T(c cdot v) = c cdot T(v)$ (where $c$ is a scalar).

## IV. Practical Transformation Example (11:02-17:28)

*   **Transformation Definition:** A mapping $T: mathbb{R}^2 \to mathbb{R}^3$ defined by:
    $T(x_1, x_2) = \begin{bmatrix} x_1 + 3x_2 \ 5x_2 - x_1 \ 4x_1 + x_2 end{bmatrix}$
*   **Steps to represent as a matrix:**
    1.  Evaluate $T$ at standard basis vectors of $mathbb{R}^2$:
        *   $T(e_1) = T(1, 0) = \begin{bmatrix} 1+3(0) \ 5(0)-1 \ 4(1)+0 end{bmatrix} = \begin{bmatrix} 1 \ -1 \ 4 end{bmatrix}$
        *   $T(e_2) = T(0, 1) = \begin{bmatrix} 0+3(1) \ 5(1)-0 \ 4(0)+1 end{bmatrix} = \begin{bmatrix} 3 \ 5 \ 1 end{bmatrix}$
    2.  Construct matrix $A$ using these results as columns:
        $A = \begin{bmatrix} 1 & 3 \ -1 & 5 \ 4 & 1 end{bmatrix}$
*   **Final Result:** The transformation can be computed as $Ax$:
    $T(x) = \begin{bmatrix} 1 & 3 \ -1 & 5 \ 4 & 1 end{bmatrix} \begin{bmatrix} x_1 \ x_2 end{bmatrix}$

## Linear Transformation: 2D Rotations (0:00-17:52)

### Definitions

*   **Linear Transformation:** A mapping $T$ from a vector space to itself that preserves vector addition and scalar multiplication. To verify, one must show:
    *   **Additivity:** $T(x + y) = T(x) + T(y)$ (1:53-4:10)
    *   **Homogeneity:** $T(cx) = cT(x)$ (4:11-5:47)
*   **Rotation Matrix:** A $2 \times 2$ matrix $A$ used to rotate a vector $x$ in $mathbb{R}^2$ counterclockwise by an angle $\theta$ (5:51-14:11).

### Formulas & Derivations

*   **Rotation Matrix Formula:**
    $$A = \begin{bmatrix} cos \theta & -sin \theta \ sin \theta & cos \theta end{bmatrix}$$
*   **Transformation Mapping:**
    $$T(x) = Ax = \begin{bmatrix} cos \theta & -sin \theta \ sin \theta & cos \theta end{bmatrix} \begin{bmatrix} x_1 \ x_2 end{bmatrix}$$
    *   $x_1$ and $x_2$ represent the horizontal and vertical components of the input vector, respectively.
*   **Derivation via Basis Vectors:**
    *   Transformation of $e_1 = \begin{bmatrix} 1 \ 0 end{bmatrix}$ results in $\begin{bmatrix} cos \theta \ sin \theta end{bmatrix}$ (8:27-10:56).
    *   Transformation of $e_2 = \begin{bmatrix} 0 \ 1 end{bmatrix}$ results in $\begin{bmatrix} -sin \theta \ cos \theta end{bmatrix}$ (11:00-13:13).

This video explores the composition of two **linear transformations**, $S$ and $T$. Below are the core definitions, formulas, and logical proofs presented:

### Definitions & Mappings (0:00 - 4:12)

*   **Transformation S:** A mapping from set $X$ (a subset of $mathbb{R}^n$) to set $Y$ (a subset of $mathbb{R}^m$). It is represented by the matrix-vector product:
    $$S(x) = Ax$$
    Where $A$ is an $m \times n$ matrix.
*   **Transformation T:** A mapping from set $Y$ (a subset of $mathbb{R}^m$) to set $Z$ (a subset of $mathbb{R}^l$). It is represented by the matrix-vector product:
    $$T(x) = Bx$$
    Where $B$ is an $l \times m$ matrix.
*   **Composition of T with S:** Defined as a mapping from $X$ to $Z$, denoted by $T circ S$. It is constructed by applying $S$ first, then applying $T$ to the result:
    $$(T circ S)(x) = T(S(x))$$

### Proofs of Linear Transformation Requirements (6:51 - 11:14)

To prove that the composition $T circ S$ is a linear transformation, the speaker validates two fundamental laws:

1.  **Additivity:** $(T circ S)(x + y) = (T circ S)(x) + (T circ S)(y)$
    *   *Steps:* $(T circ S)(x + y) = T(S(x + y)) = T(S(x) + S(y)) = T(S(x)) + T(S(y)) = (T circ S)(x) + (T circ S)(y)$.
2.  **Homogeneity (Scalar Multiplication):** $(T circ S)(cx) = c(T circ S)(x)$
    *   *Steps:* $(T circ S)(cx) = T(S(cx)) = T(c(S(x))) = c(T(S(x))) = c(T circ S)(x)$.

### Dimensionality of the Resultant Matrix (11:14 - 11:57)

*   Because the composition $T circ S$ is a linear transformation, it can also be represented as a single matrix-vector product:
    $$(T circ S)(x) = Mx$$
*   **Dimensions:** Since $S$ maps from an $n$-dimensional space to an $m$-dimensional space, and $T$ maps from that $m$-dimensional space to an $l$-dimensional space, the resulting matrix $M$ is an $l \times n$ matrix.
